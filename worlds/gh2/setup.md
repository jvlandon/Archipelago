# Required Software

- Archipelago (most current)
- PCSX2 (any qt version, preferably 2.0 or higher)
- Guitar Hero II .iso file (legally obtained)
- The Guitar Hero II APWorld (gh2.apworld)

# Installing the AP World

1. Download the latest version of Archipelago and the AP World
2. Open the Archipelago Launcher, then search for "Install APWorld" and open it.
3. Select the gh2.apworld file.
4. In the Archipelago Launcher, search "Generate Templates" and open it.
5. This should open a folder with template .yaml files for each world you have installed. Edit the Guitar Hero II yaml to your preferences.
6. Provide your yaml to your host, or host a game yourself.

# Enabling PINE

1. Open PCSX2
2. Navigate to System->Settings
3. Select Settings, then select the Advanced option on the left.
4. Scroll down to the PINE Settings section
5. Check the "Enable PINE" box, then ensure the port number field is set to 28011
6. restart PCSX2

# Starting the Game

1. Ensure you have a fresh save file when first beginning a seed. Either clear any old Guitar Hero II data or create a new Memory Card in PCSX2.
**(Note: PCSX2's folder saves do not work with Guitar Hero II)**
2. In the Archipelago Launcher, search for "Guitar Hero II Client" and open it.
3. Open Guitar Hero II in PCSX2.
4. Enter your room information, then click "Connect". The client should notify you that PINE is connected.
5. Enter your slot name. The client should confirm your connection.
6. Get ready to rock!
